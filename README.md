# # Diwali Sales Data Analysis 📊

## 📌 Project Overview

This project focuses on analyzing **Diwali Sales Data** using Python to understand customer purchasing patterns, sales performance, and other useful business insights.

The project is developed using **Python in Jupyter Notebook / Google Colab** with data analysis and visualization techniques.

## 🎯 Objectives

* Analyze the Diwali sales dataset.
* Clean and preprocess the data.
* Understand customer purchasing behavior.
* Identify important sales trends and patterns.
* Analyze customer demographics.
* Generate meaningful business insights from the data.
* Visualize the results using charts and graphs.

## 🛠️ Technologies Used

* **Python**
* **Google Colab / Jupyter Notebook**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
